# abstract-algebra-scala3

用 Scala 3 交互式地学习抽象代数，重点关注它在编程中的应用场景。

## 为什么

抽象代数里的半群、幺半群、群、环、格等结构，在日常编程中随处可见：
并行归约、日志与指标聚合、CRDT、解析器组合子、类型类设计……
理解这些结构背后的定律，可以让代码更通用、更容易推理和测试。

## 内容规划

- 半群与幺半群：`combine`、单位元与折叠
- 群：逆元、撤销操作、对称性
- 环与域：多项式、模运算、密码学基础
- 格与偏序：CRDT、静态分析
- 函子、单子等范畴论入门（与代数结构的联系）

每个主题都会配有可运行的 Scala 3 代码和用来检验代数定律的测试。

## 快速开始

需要 JDK 17+ 和 [sbt](https://www.scala-sbt.org/)。

```bash
sbt run    # 运行示例
sbt test   # 检验代数定律
sbt console  # 打开 REPL 交互式探索
```

## 目录结构

```
src/main/scala/algebra/   代数结构定义与示例
src/test/scala/algebra/   定律测试
```
